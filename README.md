# 📊 QoS Network Analysis using Python & TShark

This application is designed to analyze **Quality of Service (QoS)** network parameters using packet capture files (`.pcapng`) generated by Wireshark.  
The analysis is performed using **TShark (Wireshark Command Line Interface)** and processed with **Python** to produce structured and measurable QoS results.

---

## ✨ Features
- Batch processing of multiple Wireshark capture files
- Automatic calculation of QoS parameters:
  - Throughput (kbps)
  - Delay (ms)
  - Jitter (ms)
  - Packet Loss (%) *(placeholder)*
- Average value calculation for each parameter
- Export results to Excel (.xlsx)
- Console output for quick review

## ▶️ How to Run
1. Place all `.pcapng` files in the same directory as the Python script
2. Open terminal or command prompt

4. The program will:

- Calculate QoS parameters
- Display results in the terminal
- Save the results to an Excel file

## 📊 QoS Parameters Calculation

### Throughput (kbps)
Throughput = (Total packet size × 8) / Duration / 1000

### Delay (ms)
Delay = Total delay / Total received packets

### Jitter (ms)
Jitter = Total delay variation / Total received packets

### Packet Loss (%)
Packet loss is not calculated directly from the capture file and is currently set to:
0.0  
This value acts as a placeholder for future implementation.

## ⚠️ Notes
- A minimum of 2 packets is required to calculate delay and jitter
- Capture files with insufficient packets will return zero values
- Packet loss calculation requires sequence-based or sender–receiver analysis
- Suitable for:
  - Network performance analysis
  - QoS evaluation
  - Academic research (final project / thesis)
